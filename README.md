# DevOps Week 02

A Git and GitHub collaboration exercise built during the Davine Technologies DevOps Internship.

## Project Structure
- app.py - main application logic (login and logging features)
- requirements.txt - project dependencies
- script.js - sample JavaScript file
- style.css - sample stylesheet
- config.txt - sample configuration file

## Workflow Practiced
- Created two feature branches (feature-login, feature-logging)
- Made independent changes in each branch
- Merged both into main
- Resolved a real merge conflict in app.py
- Opened a Pull Request for final review
